# `gop path` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only `gop path` command that prints the source repository path or a resolved managed outpost path for shell navigation.

**Spec:** `docs/superpowers/specs/2026-07-03-gop-path-spec.md`

**Architecture:** Keep path resolution in `outpost-core` as a small operation under `ops::path`, because selector semantics already live in core and the CLI should only parse arguments and print the resulting path. Reuse existing context classification in `crates/cli/src/main.rs`: from a source repo, `path src` prints that source; from an outpost, `path src` prints the outpost's source; `path <outpost>` resolves a selector through the relevant source registry. Use existing `OutpostSelector` behavior so `<outpost>` means the same path-or-ID style selector used by lifecycle commands.

**Tech Stack:** Rust workspace, `clap` CLI parsing, existing `outpost-core` selector and registry APIs, existing CLI e2e fixture.

## Global Constraints

- User-facing behavior is defined by `docs/superpowers/specs/2026-07-03-gop-path-spec.md`.
- Do not introduce a second navigation registry or shell-specific state.
- Do not change existing `add`, `remove`, `lock`, `unlock`, `move`, `list`, `status`, or `analyze` behavior.
- `src` is a reserved `gop path` target for the source repository path.
- `gop path <outpost>` resolves an existing managed outpost; stale or unregistered entries should fail through existing selector/safety errors.
- Print exactly one path followed by `\n` on stdout on success.
- Keep diagnostics on the existing CLI error path.
- Documentation changes must describe the binary `gop path` command, not the shell function layer.

- [ ] **Step 3: Add the core operation**

Create `crates/core/src/ops/path.rs`:

```rust
use std::path::PathBuf;

use crate::selector::{OutpostSelector, resolve_live_entry};
use crate::{OutpostResult, SourceRepo};

pub enum PathTarget {
    Source,
    Outpost(OutpostSelector),
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PathReport {
    pub path: PathBuf,
}

pub fn run(source: &SourceRepo, target: PathTarget) -> OutpostResult<PathReport> {
    let path = match target {
        PathTarget::Source => source.work_tree().to_path_buf(),
        PathTarget::Outpost(selector) => resolve_live_entry(source, &selector)?.path,
    };

    Ok(PathReport { path })
}
```

pub struct PathArgs {
    #[arg(value_name = "src|OUTPOST", value_parser = parse_path_target)]
    pub target: PathTargetArg,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum PathTargetArg {
    Source,
    Outpost(PathBuf),
}

fn parse_path_target(value: &str) -> Result<PathTargetArg, String> {
    if value == "src" {
        Ok(PathTargetArg::Source)
    } else {
        Ok(PathTargetArg::Outpost(PathBuf::from(value)))
    }
}
